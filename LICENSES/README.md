# Third Party Licenses

This directory holds copies of the license files of the third party libraries vendored under [`lib/`](../lib). They are kept here so all third party licenses can be found in one place. GXDE Roller's own license is [`COPYING`](../COPYING) (GNU GPL v3).

The files here are copies. The original files inside `lib/` are authoritative, and the license statement at the top of each source file takes precedence. See [`lib/README.md`](../lib/README.md) for version and modification details of each library.
